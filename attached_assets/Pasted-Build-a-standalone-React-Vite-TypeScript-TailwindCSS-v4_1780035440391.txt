Build a standalone React + Vite + TypeScript + TailwindCSS v4 single-page application
called "LV= Reporting System" that recreates the DANAD96 Reporting System screen from
the LV= CLANAD legacy application, styled with the LVE Component Library design system.
No backend. All data is hard-coded. Static deployment only.

7. DatePicker COMPONENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
A date input that:
- Displays the current value as a string (dd/MM/yyyy format).
- When clicked, opens a calendar popup (month/year nav, day grid).
- Selected date rendered in the input field formatted as dd/MM/yyyy using date-fns format().
- Uses MdKeyboardArrowDown chevron on the right (same style as SystemNameSelect).
- Accepts props: value (string dd/MM/yyyy), placeholder (string),
  disabled (boolean), onChange (d: Date | null) => void.
- When disabled=false the picker is fully interactive.
- Calendar popup appears below the input (absolute positioned).
  Month/year header with prev/next arrows.
  Day grid 7 columns (Mon–Sun headers).
  Selected day: bg-[#006cf4] text-white rounded-full.
  Today: border border-[#006cf4] rounded-full.
  Click day → call onChange(date), close popup.
- install date-fns for date formatting.

9. SYSTEM NAME CHANGE LOGIC
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
When the user picks a new system name:
  1. Reset selected row to 0.
  2. Apply date defaults per system (see section 8 above).
  3. Classification rules:
 
  NOT_IN_ORACLE = { "CCRP", "MARKETING", "PLI ADMIN", "SALES95" }
    → Clear Start/End dates to ""
    → Show Warning popup: "System {name} is not present in ORACLE database!"
    → Show EMPTY report list (no rows)
 
  EMPTY_NO_WARNING = { "HIPPS97", "ILA REPORTS", "MORTGAGE ANNUIT(Admin)",
                        "MORTGAGE ANNUIT(NB)", "PC96", "PROPSALE97" }
    → Clear Start/End dates to ""
    → Show EMPTY report list (no rows), no popup
 
  All other systems → show their specific list + date defaults from section 8.
  Default fallback (any system not explicitly mapped) → show DANAD96 report list.

13. ACCEPTANCE CRITERIA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- Default state shows DANAD96 Reporting System with its 39 reports, first row selected.
- Switching system name updates the header title, report list, and dates correctly.
- NOT_IN_ORACLE systems show Warning popup and empty list.
- EMPTY_NO_WARNING systems silently clear dates and show empty list.
- Clicking Print always shows the Error:200 popup.
- Selecting a row in the table highlights it blue (#006cf4) and shows its path in the footer input.
- DatePicker allows picking start/end dates from a calendar popup.
- All fonts, colours, radii, and spacing match the LVE design tokens exactly.
- App is fully static, no API calls, no authentication.
